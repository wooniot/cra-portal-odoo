CRA-Portal Connector

Cyber Resilience Act compliance status inside Odoo — product keurmerk, verify links and the 24h/72h incident process.

What it does

  • CRA Compliance tab on products — live keurmerk status (compliant / in progress / not compliant), the public verify link and badge, matched to CRA-Portal on the product SKU.
  • One-click sync — Action → Sync CRA status refreshes every product in a single call.
  • Incident-ready — a direct link to the self-service incident-response tool: the CRA Article 14 reporting process (RACI, 24h / 72h / final report) plus a tabletop drill.
  • NIS2 — organisation readiness is available via the companion NIS2-Portal Connector module.

How it works

Odoo is your base ERP; CRA-Portal (Regulation (EU) 2024/2847) delivers the compliance engine. This connector talks to your CRA-Portal Partner-API over a secure key. Configure it under Settings → CRA-Portal and press Test connection.

Requirements

  • An active CRA-Portal subscription and a Partner-API key (scopes products:read, keurmerk:read).
  • Python requests on the Odoo server.

Getting started

  1. Subscribe at cra-portal.eu and generate a Partner-API key.
  2. Install this module, open Settings → CRA-Portal, paste the key and press Test connection.
  3. Give products an Internal Reference (SKU) that matches CRA-Portal and run Action → Sync CRA status.

Pricing: the module is free. Compliance data is delivered through your CRA-Portal subscription (from €49/month). See cra-portal.eu for tiers.
